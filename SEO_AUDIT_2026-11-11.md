# JustPDFit — SEO and AI search audit
Date: 2026-11-11
Website: https://justpdfit.com/

## Accurate product positioning
Advanced Edit PDF features are free; PDF export with four discreet clickable corner watermarks per page is free. Removing all watermarks is optional and costs €1.99 per document, without subscription.

Working editor features:
- Place and format movable text blocks.
- Insert dates and checkboxes.
- Type, draw or import signatures and initials.
- Place PNG/JPG images and highlights.
- Edit multiple PDF pages and duplicate, move or resize elements; undo/redo.
- Local PDF export with clickable marks or optional clean export.

Not supported: rewriting words already embedded in the original PDF; qualified electronic signature certification. PDF-to-Word, Word-to-PDF and real PDF compression remain under development.

## Existing search bot controls
robots.txt allows OAI-SearchBot, ChatGPT-User, Claude Search and generic web crawlers, while GPTBot training crawls remain independently disallowed. Search indexing permission does not imply AI model-training permission.

## Checks and unresolved audit work
- GitHub source confirms new canonical page templates and localized content; public 200 status / browser rendering still needs live-crawl verification after deployment.
- The sitemap includes 27 language hubs, 162 tool pages and 8 default canonical URLs. The sitemap uses Google-compatible tl for Filipino alternates on /fil/ URLs. Some generated HTML also contains fil alternates; harmonize to tl if Search Console flags them.
- Google Search Console data could not be queried because the GSC Wizard subscription returned payment_required. No real ranking, clicks, impressions or indexing status has been verified.
- Run live URL Inspection, structured data tests, PageSpeed Insights/Core Web Vitals and language-native editorial QA.
- Monitor queries and landing pages per language and prioritize content based on genuine user demand. Avoid bulk keyword stuffing, fictitious certifications and unavailable-tool claims.
- Google and AI search engines determine discovery, indexing, ranking and citation independently. There are no guaranteed rankings.
