# JustPDFit.com website

The official multilingual, privacy-first PDF website: https://justpdfit.com/

- Repository: https://github.com/zmehanna/justpdfit-web
- Deployment: GitHub Pages, branch `main`, directory `/(root)`
- Custom domain: `justpdfit.com`, configured via GitHub Pages and `CNAME`
- 27 languages: `i18n*.js`, `flags/`, and `legal-locales/`
- Native iOS application is managed independently: https://github.com/zmehanna/Pdf-ios

All web assets live in this repository. Pushing website changes here will not
trigger the iOS application's Xcode Cloud workflow.

Migrated on 2026-11-09 from `docs/` in `zmehanna/Pdf-ios`.
