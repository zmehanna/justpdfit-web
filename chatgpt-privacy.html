JustPDFit ChatGPT App — Privacy Notice

Last updated: 11 November 2026. Publisher: KL-MEHANNA LLC / JustPDFit.

This notice applies specifically to the JustPDFit integration inside ChatGPT. It is different from the local-browser processing features at JustPDFit.com.

1. PDF data you submit

When you intentionally use a PDF operation in the ChatGPT app, the PDF or image bytes and any editing instructions are sent to JustPDFit's external MCP server, currently hosted by Render in Frankfurt, Germany. Processing is remote, not solely on your device. Do not upload documents containing information you are not authorized to share.

2. Processing and outputs

The app processes files in server memory and sends resulting PDF bytes back to ChatGPT. The current application has no built-in user accounts or intentional persistent PDF database. However, infrastructure providers and ChatGPT may process, cache or retain requests and outputs under their own applicable terms and service controls. Do not assume that data is end-to-end encrypted or that all copies are immediately erased. We do not sell document content or intentionally use it to train models.

3. Technical information

Server providers may process IP addresses, timestamps, request metadata, network diagnostics and security logs. ChatGPT processes conversation content and tool interactions under OpenAI's terms and privacy practices. The app does not currently use advertising trackers.

4. Security and limitations

Transport uses HTTPS. This preview has not completed independent security certification. Avoid highly sensitive, confidential, regulated or classified documents until production security controls are independently validated.

5. Your choices

You can choose not to use the integration and instead use local PDF functionality at JustPDFit.com. Do not submit files unless you consent to remote processing. To request help or report a privacy concern, use JustPDFit Support.

6. Updates

This notice may change as the integration matures. Material processing changes should be reflected here before release.
